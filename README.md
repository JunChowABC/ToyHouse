# 晚安，玩具屋 · 核心玩法原型

基于《晚安，玩具屋》GDD V1.3 制作的无依赖浏览器原型。首个完整盘面使用项目讨论中已验证可解的 Test Level A 数据：14×20 隐形网格、70 个不同长度玩具、9 层释放结构。

## 启动

在当前目录运行：

```powershell
npm start
```

然后打开 `http://127.0.0.1:4173`。

## 操作

- 点击玩具：尝试沿其面对方向离场
- 玩具前方有空位时：自动滑到第一个阻挡前并停下，不会回到原位
- `1`：消除道具，依次选择两个玩具直接移除
- `2`：洗牌道具，随机改变五个玩具的方向
- `3`：翻转道具，选择一个玩具使其方向反转
- `H`：提示一个当前可离场玩具
- `R`：重开当前关
- `F`：切换全屏
- `Enter` / `Space`：开始或进入下一关

## 已实现

- 14×20 高密度竖向盘面
- 每关 55～70 个 Toy，第一夜共 10 个测试关
- S / M / L / XL 四档长度与四方向
- 占格与头部到边界的完整路径检测
- 盘内滑动、遇阻停止和永久位置变化
- 快速离场、阻挡摇动、Combo、连锁释放提示
- 消除两个、随机改向五个、指定翻转一个三种道具
- 无限 Hint、Restart、普通关结算与第一夜晚安演出
- `window.render_game_to_text()` 与 `window.advanceTime(ms)` 自动化测试接口

## 验证结果

- 10 个关卡启动时均通过自动可解性检查
- 已自动验证：首页 → 阻挡反馈 → 合法离场 → Hint → Restart → 单关结算
- 已自动连续清空 1-1 至 1-10，并进入“第一夜 · 晚安”章节演出
- 已验证部分通路移动后停在阻挡前、贴住阻挡时原地反馈、移动后重开恢复
- 已验证三种道具的目标选择、数量、方向变化和视觉选中态
- 最新自动化输出与截图位于 `output/web-game/`

## GitHub Pages 发布

`docs/` 是可直接作为 GitHub Pages 发布目录的混淆版本，入口为 `docs/index.html`。仓库推送到 `main` 后，`.github/workflows/pages.yml` 会自动部署 Pages。

说明：浏览器端代码必须交付给用户设备执行，因此不存在绝对意义上的客户端加密；本项目使用 Terser 进行压缩与变量混淆，源代码仍保留在仓库根目录供维护。
