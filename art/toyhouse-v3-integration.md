## 布局与真实状态

- UI 从 941×1672 等比映射到 540×960。标题上方兔子保持 V3 的 `(426,27)` 图层位置和原比例；不再额外拉长。
- 标题使用 PSD 双行位置，显示实际关卡编号、20 关名称。金币、库存和 Combo 来自存档/运行状态；星星系统未实现，显示 `—`，资源加号保留为未接入的装饰入口。
- 左上页签打开暂停菜单；原继续、重开、退出、音乐、音效、震动设置保留。
- 地毯显示区域为 `(3,171,534,667.26)`；棋盘为 `(66,208)` 起、12×18 格、每格 34 像素，格子数据与玩具占格不变。鼠标/触摸按同一棋盘映射。
- 同类玩具统一固定尺寸，按密集处的安全尺寸设置，取消所有邻居驱动的逐只缩放。以34px格和3px内缩边距等比适配：在固定适配尺寸基础上统一乘1.44，兔子、小鸭短边约44.64px，鲸鱼按其完整长形原画等比显示；同类玩具跨位置、朝向、关卡、消除前后保持同样大小。逻辑占格不变，点击映射随棋盘间距同步。
- 普通飞出采用900ms缓起缓停；小鸭每格110ms、最短500ms。结算等待所有动画结束，暂停冻结动画。
- 首页、道具说明和晚安演出同步新原画。弹窗结构由现有绘制逻辑保留，装饰底板换用 V3。

## 复现与验收

1. 使用带 Pillow、psd-tools 的 Python 运行 `python scripts/export-v3-art.py`。工作站已有 PSD 依赖路径在脚本中复用，无需 Photoshop。
2. 运行 `npm run build` 更新关卡模块、压缩发布脚本和新资源目录。
3. 启动 `npm start`，打开 `http://127.0.0.1:4173/`；`/docs/` 验证发布副本。
4. 执行 `npm run test:art`，以及 `tests/verify-tool-economy.mjs`、`tests/verify-pause-menu.mjs`、`tests/verify-impact-combo.mjs`、`npm run test:levels`。

美术验收覆盖源/发布 PNG 字节一致、无旧资源请求、玩具和标题兔子绘制矩阵等比、标题兔子位置、完整地毯、首页/关卡 1/关卡 16/选中/暂停/Combo、540×960 / 390×844 DPR2 / 1024×768 三种视口，以及页面错误/资源失败检查。截图和报告见 `test-output/v3-art/`。标准 web-game 客户端记录见 `test-output/v3-integration/client-final/`。

旧 `toyhouse-v5` 文件保留为历史资源；当前入口、构建和运行时均使用 `toyhouse-ui-v3`。本次同步本地发布包，不包含远程推送或部署。

补充验收：`node tests/verify-toy-spacing.mjs` 检查源码和发布版全部20关的初始盘面、移出3只玩具后的盘面，通过 Canvas 实际绘制矩阵测量所有玩具图像边界，检查实际透明轮廓接触面积（每对不超过较小图像面积2%，允许极少量边缘相接），且同一原画在所有位置、朝向、关卡和消除前后的实际绘制尺寸一致。报告：`test-output/toy-spacing/report.json`。

当前为用户要求再次放大20%的预览档（1.2×1.2=1.44）。Combo数字使用深紫#63345f与3px奶油白#fff5df描边。密集处接触增加；本档使用 `verify-toy-spacing.mjs --measure-only` 验证同类固定尺寸并记录接触面积，不声称满足上一档2%严格门槛，默认严格测试门槛保留。
