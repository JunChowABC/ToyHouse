# 十种关卡机制实现与验收 v1.5

日期：2026-09-29。范围：用户要求补齐余下四种机制，承接《六种关卡机制实现与验收-v1.4.md》，当前本地 Web 共支持十种机制。本说明补充原设计中的执行细节；原文的阶段性建议不代表当前实现范围。

## 四种新增机制

| 机制 | 配置 | 实际行为 |
|---|---|---|
| 冰冻 | 玩具 `modifier: FROZEN`，`ice_layers: 1/2` | 兔子或鲸鱼无法主动移动、翻转或被洗牌选中；每次受碰撞减少一层，零层恢复操作。冰冻占格保留，可被区域搬运。 |
| 单向出口 | 边界格 `ONE_WAY_EXIT`，`direction` | 仅允许对应方向穿出；不影响其他边界。错误方向停在出口前。小鸭按实际离场方向判断，受限时继续寻找其他出口，角格可选择合法朝向。 |
| 传送带 | 矩形 `CONVEYOR`，`direction`、`period` | 完整位于区域内的玩具同时沿带方向移动一格；包含冰冻、睡眠和抱抱状态。跨区域玩具不参与。不能推出盘面、推动外部玩具或穿越障碍。 |
| 旋转区 | 3×3 或 4×4 `ROTATOR`，`clockwise`、`period` | 完整位于区域内的兔子、鲸鱼以头格为轴转90°，同步改变朝向及占格，小鸭不旋转。旋转后全部占格须留在区域内。 |

区域的所有目标格基于同一占格快照计算，忽略参与移动玩具的旧格。任一目标越界、被外部对象占据或与其他目标重叠，取消该区域整组动作，不能只移动一部分。

## 补充时序约定

- 区域采用确定性的点击回合触发，不采用现实时间计时。`period` 范围1～8，默认1；新增正式关卡使用2。区域上显示距下次触发的点击数。
- 正常兔/鲸的手动点击在移动、碰撞、钥匙与直接解锁结算后推进区域一次；被普通阻挡的点击也可推进。点击被冻结/睡眠/抱抱锁定的玩具、传送循环无效动作不推进。
- 小鸭连锁、道具和等待时间不推进区域。区域结算后再检查自动离场。暂停不推进游戏时间；重开恢复区域计数与初始布局。
- 多区域按实体ID排序依次处理；区域不可重叠。被前一区域带入后一区域的玩具可参与后一区域本回合动作。
- 周期相位写入状态哈希，求解器区分不同相位；触发被阻止也消耗本次周期。
- 弹簧按2026-09-30用户修正规则：不可点击移动；受撞后持续滑行至障碍前或离场；停下后仍阻挡，可再次被撞动，不再缩回底座。

## 新增关卡与编辑器

保留1～100关，追加配置 `config/extra-mechanic-levels-v1.5.json`：每关72只玩具，均有完整无道具解法和实际机制触发证明。

| 关卡 | 组合 |
|---|---|
|101|冰冻|
|102|冰冻＋纸箱|
|103|单向出口|
|104|单向出口＋冰冻|
|105|传送带|
|106|传送带＋冰冻|
|107|旋转区|
|108|旋转区＋单向出口|
|109|四种新机制组合|

编辑器 `/editor/` 或构建版本 `/docs/editor/` 支持十种机制池、冰层、方向、区域尺寸、周期及旋转方向。物件下拉列表可选中玩具下方区域；修改后原解法失效，需重新求解。候选生成、依赖图、事件预览、试玩和JSON导入导出复用同一规则模块。配置结构沿用兼容的 `schema_version: 1.4`，实现版本为v1.5。

生成器依然复用现有释放布局并嵌入机制，再搜索验证；不代表任意依赖图反向布局生成已完成。难度与连锁目标用于候选评分，尚未完成严格档位批量校准。新增单向出口关卡包含实际合法通过；错误方向拦截另有独立规则及浏览器用例。
