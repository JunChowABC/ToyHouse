## 3. 本版锁定结论

1. 手动玩具撞到其他玩具时，主动玩具与被撞玩具在接触发生的同一时刻播放撞击反馈，不得延迟。
2. 手动玩具遇盘面边界或其他阻挡而停下时，也必须播放撞击反馈。
3. 同一关同一功能原型只显示一种皮肤；当前默认功能玩具为兔子 1×2、小鸭 1×1、大鲸鱼 1×3。
4. 小鸭不按面朝方向判定；只要能经上、下、左、右空格到达任意边缘缺口，就自动寻路离场。
5. 每次占格变化后立即逐轮扫描小鸭，直到没有符合条件的小鸭；每只鸭分别增加 Combo，动画允许并行。
6. 小鸭逻辑连锁完成后恢复输入，不等待所有离场动画串行播放完毕；连锁期间锁定玩具、三个局内道具和暂停入口。
7. Combo 倒计时为 8.000 秒。下一只有效离场必须发生在归零前；恰好 8.000 秒视为旧 Combo 已中断，当前玩具从 Combo 1 重新开始。
8. Combo 为 0 时进度条隐藏；数量与统一粉色进度条同组显示，无秒数和待归位小字。
9. 局内底部不显示提示与重开常驻按钮；右上角暂停弹窗承载设置、重新开始、继续游戏和退出关卡，暂停期间 Combo 与全部游戏时钟冻结。
10. 普通关卡完成反馈属于核心玩法 UI；夜晚终关完成只引用章节系统演出。
11. 第一夜前 10 关只使用 1×2 普通兔子；后续关卡先加入 1×1 自动离场小鸭，再加入 1×3 大型鲸鱼。

12. 各道具初始 0，每种每关最多 3 次；点击先打开说明，有库存使用，无库存购买 100 金币并立即进入使用流程。
13. 金币、库存与按关卡 ID 的已用次数保存；重开和刷新不重置同关次数，新关独立计数。初始金币 0 为暂设，任务/成就/广告只预留接口。
14. 圆形地毯、放大兔子、耳朵表示前进方向，不使用侧躺造型、长方形外框或箭头；无局内飘字，标题单行“第01关·月光敲敲窗”。

## 4. 数据成熟度

### 4.1 正式值

- Combo 超时：8000 ms。
- Combo 连续条件：两次有效离场间隔严格小于 8000 ms。
- 兔子、小鸭、鲸鱼占格：1×2、1×1、1×3。
- 小鸭四方向寻路、逐轮扫描、逐只计数、动画可并行。
- 自动连锁锁定范围、暂停冻结规则、Combo 归零显示模式。

### 4.2 测试数据

- 撞击反馈 180 ms。
- 旧提示强调 1200 ms（已停用，仅历史追溯）。
- Combo 数字刷新缩放 160 ms。
- 普通关卡完成反馈最短展示 800 ms。
- 玩具资源 ID 300101～300103。

测试数据只用于原型和手感验证，未获得正式依据前不得静默转为上线值。
