# 2. 需求概述

## 2.1 设计目的

| 字段 | 内容 |
| --- | --- |
| 设计目的分类 | 主：核心玩法；辅：基础功能 |
| 一句话目的 | 在不遮挡高密度盘面的前提下，让玩家清楚读取关卡、Combo、三道具和暂停状态，并安全完成继续、重开或退出操作。 |
| 成功判据 | 控件无误认；出口无遮挡；暂停与道具状态可辨；动态文字可读；所有热区与安全区通过实机验收。 |
| 不做的影响 | 玩家无法稳定区分玩具与控件，容易误触；暂停、重开、退出和设置操作缺少统一入口。 |
| 优先级 | P0，核心玩法 MVP 必需。 |

## 2.2 需求范围

- 局内 HUD、关卡标识与 Combo 进度条；
- 右上暂停入口；
- 底部【消除】【洗牌】【翻转】三个道具；
- 第一关自动引导 Spotlight；
- 后续关卡小鸭自动连锁 Tips；
- 暂停弹窗：音乐、音效、震动开关，以及重新开始、继续游戏、退出关卡；
- 普通关卡完成反馈；
- 与原画、动作、特效和程序设置状态的接口。

## 2.3 明确移除的旧需求

- 不制作局内常驻【提示】按钮及灯泡图标；
- 不制作局内常驻【重新开始】按钮及回转箭头图标；
- 不制作“重新开始？”二次确认弹窗、取消按钮或确认重新开始双按钮布局；
- 不制作“无合法提示目标”专用 Tips；配置不可解属于关卡数据异常，不再通过玩家提示按钮暴露；
- 重开入口只存在于暂停弹窗内。

## 2.4 不在本次范围

- 玩具、盘面、卧室场景与装饰：归原画-ADD；
- 撞击粒子、引导星轨、完成星光和 Combo 刷新闪光：归特效需求；
- 玩具移动、回弹、转身、离场动作：归动作需求；
- 夜晚终关演出、关卡选择、玩具屋主界面、商店、收集、经济、广告 UI；
- 第一夜之后的具体小鸭/鲸鱼关卡布局。

## 2.5 统一风格基准

1. 柔和粉彩、扁平二维、精致娃屋与轻纸片感；主色奶油白、浅粉、淡紫，薄荷绿与浅蓝仅作辅助，暖金只作小面积高光。
2. 体积感限于细描边、轻内阴影与极浅高光；禁止写实塑料、厚重 3D、强镜面、霓虹或竞技 HUD。
3. HUD 像娃屋中的柔软布牌、奶油糖牌或小铭牌；控件轮廓不得近似 1×2 兔子，避免误认。
4. 标题与按钮使用圆润、易读的中文字体；正式字体和商用授权标记 `[待确认]`。
5. 暂停遮罩使用偏灰紫的半透明色；测试稿可参考约 70% 不透明度 `[测试参考]`，最终以实机可辨认盘面但明显失焦为准。
6. 暂停主底板采用奶油色，标题带与主按钮采用柔和粉色；危险语义不得使用鲜红警告、爆炸或裂纹。

## 2.6 复用原则

- 三个底部道具共用一套等宽底板、圆角、描边、阴影和四态规范，只更换图标与动态副文案。
- 暂停弹窗的次按钮可复用通用奶油按钮；【继续游戏】使用独立主按钮配色。
- 音乐、音效、震动共用设置行与开关组件；图标独立交付。
- 动态关卡名、Combo 数、按钮文字、道具副文案均由程序文本实现，不烘焙进图片。
- 所有 normal/hover/press/disabled 状态保持同画布尺寸与同锚点。

# 4. UI 需求

## 4.1 局内玩法主界面

### 4.1.1 页面信息

- 页面用途：承载关卡、Combo、三个道具和暂停入口，同时完整露出高密度盘面与四周出口。
- 页面入口：关卡加载、盘面展示与开局逻辑完成后。
- 页面退出：普通关完成进入下一关；夜晚终关进入章节系统；暂停内退出返回玩具屋。
- 对应原型：[局内玩法界面交互原型 v1.1](../../assets/局内玩法界面-交互原型.svg)。

### 4.1.2 页面外观总述

页面保持“场景为主、HUD 为辅”。顶部使用轻薄承托区放置关卡、Combo 和右上暂停；底部仅放三个等宽道具。暂停按钮采用明确双竖线语义，不再出现回转箭头。第一夜前十关的合成状态稿只放 1×2 普通兔子，并表现中央 10×14 密集区与四周 2～3 格留白。

### 4.1.4 核心状态示意稿

- 状态 A：默认可操作，Combo 隐藏，三道具与暂停可用。
- 状态 B：Combo 进行中，条内显示“连击 ×12”，不显示秒数。
- 状态 C：消除或翻转道具选中，底板选中态明显，盘面目标选择中。
- 状态 D：后续关卡自动连锁，显示“小鸭正在回家”，盘面、三道具与暂停禁用。
- 状态 E：第一关自动引导 Spotlight，仅目标兔子突出，无提示按钮。
- 状态 F：完成等待，全部局内输入禁用，暂停入口不可操作。
- 状态 G：异形屏安全区，关卡、暂停、三个道具和四周出口均不被裁切。

每个状态至少提交一张 1080×1920 合成示意图，可在同一 PSB 中以独立组管理。

## 4.2 暂停弹窗

### 4.2.1 页面信息

- 页面类型：模态暂停弹窗。
- 页面入口：玩家操作阶段点击右上【暂停】。
- 页面用途：冻结局内时钟，集中承载设置、重新开始、继续游戏和退出关卡。
- 页面退出：【继续游戏】返回冻结点；【重新开始】恢复初始盘面；【退出关卡】返回玩具屋。
- 对应原型：[暂停弹窗交互原型 v1.1](../../assets/暂停弹窗-交互原型.svg)。

### 4.2.2 页面外观总述

背景使用偏灰紫遮罩降低明度与饱和度，但保留当前盘面位置可辨。中央面板像厚实奶油卡纸或软布牌，顶部粉色标题带写“暂停”。设置行纵向排列，开关统一右对齐；三个操作按钮纵向排列，【继续游戏】为粉色主按钮，【重新开始】和【退出关卡】为奶油色次按钮。不得加入参考图中的广告、跳关、背景轮播、货币或奖励入口。

### 4.2.4 状态与动效稿要求

- 状态 A：默认打开，三项设置显示当前状态，【继续游戏】为默认焦点。
- 状态 B：任一开关关闭，轨道、滑块位置和颜色同时变化。
- 状态 C：重新开始按钮按下态；松开后弹窗退出并恢复初始盘面。
- 状态 D：继续游戏按钮按下态；弹窗淡出，所有局内计时从冻结点恢复。
- 状态 E：退出关卡按钮按下态；返回玩具屋。
- 状态 F：窄屏/异形屏适配，标题、三设置和三按钮完整可见。

动效测试参考：遮罩 0～100% 约 120ms，面板淡入并由 96% 缩放到 100% 约 180ms，按钮按压反馈不晚于 50ms；以上均为 `[测试参考]`，最终以实机评审为准。暂停逻辑必须在动效开始前立即生效。

# 5. 资源命名与交付规范

## 5.1 命名规则

- 全小写、下划线分隔、无中文、无空格、无特殊字符。
- 按钮：`btn_模块_功能_状态`，如 `btn_pause_resume_press.png`。
- 图标：`icon_模块_功能_尺寸`，如 `icon_tool_shuffle_96.png`。
- 面板：`panel_模块_功能`，如 `panel_pause_header.png`。
- 开关：`toggle_pause_on/off/press/dis.png`。
- 进度条：`bar_combo_bg.png`、`bar_combo_fill.png`、`mask_combo.png`。
- 全屏层：`overlay_模块_功能`。
- 动态文字图层添加 `@_Dynamic`；仅制作参考、不导出的图层添加 `@_Hide`。

## 5.2 Godot 交付口径

1. 整页视觉稿按 1080×1920 制作；独立运行时纹理优先使用 128、256、512、1024 等规格。
2. 交付 PSB/PSD 分层源文件和 PNG-32；禁止 JPG。
3. Godot 对应使用 `NinePatchRect`、`TextureButton`、`TextureProgressBar`、`Label`、`CanvasLayer` 与 Shader。
4. 九宫格保留完整边框与切片说明；按钮所有状态同尺寸、同锚点。
5. 动态文字不栅格化；运行时 PNG 导出前处理图层样式与智能对象。
6. PNG 透明边缘无白边、黑边或半透明脏点。
7. 暂停开关的滑块位置由程序状态驱动；美术不把开关文字烘焙进切图。

# 6. 验收标准

## 6.1 基础规范验收

| 检查项 | 标准 | 严重程度 |
| --- | --- | --- |
| 命名 | 全小写、下划线、无中文与空格 | 致命 |
| 文件格式 | 分层 PSB/PSD + PNG-32 | 致命 |
| 状态完整 | 道具、暂停、弹窗按钮和开关状态齐全且同尺寸 | 致命 |
| 九宫格 | 拉伸区域不破坏边框、圆角和纹理 | 致命 |
| 动态文字 | 关卡、Combo、道具、暂停和完成文字均可编辑 | 主要 |
| 透明边 | 无白边、黑边、脏点 | 主要 |

## 6.2 页面视觉与交互验收

| 检查项 | 合格标准 | 严重程度 |
| --- | --- | --- |
| 盘面可见性 | HUD、道具和装饰不遮挡四周出口 | 致命 |
| 常驻按钮精简 | 局内没有提示、重开常驻按钮；底部仅三道具，右上仅暂停 | 致命 |
| Combo | 数量在条内；无秒数；Combo=0 整组隐藏 | 致命 |
| 三道具 | 三者等宽、语义可区分、选中/禁用不只依赖颜色 | 致命 |
| 暂停入口 | 双竖线语义明确；不可与重开、设置混淆 | 主要 |
| 暂停层级 | 遮罩阻断背景；继续为主按钮；三设置与三操作路径清楚 | 致命 |
| 暂停冻结表达 | 暂停状态与局内状态有明显层级差；背景仍能辨认当前盘面 | 主要 |
| 完成反馈 | 无奖励、无按钮、无大结算面板 | 主要 |
| 风格 | 粉彩娃屋感统一，无塑料 3D、竞技 HUD 或参考图广告元素 | 致命 |
| 多分辨率 | 刘海、圆角、底部手势区无裁切与错位 | 主要 |
| 点击热区 | 暂停≥96×96px；单个道具≥144×96px `[测试数据]` | 主要 |
| 可访问性 | 开关和按钮状态同时使用位置、形状/描边与颜色表达 | 主要 |

## 6.3 功能状态验收

1. 暂停打开首帧必须显示遮罩和弹窗；美术入场动效不得延迟逻辑暂停。
2. 暂停超过 8 秒后继续，原 Combo 数量与进度视觉保持；不制作“暂停后归零”状态稿。
3. 【重新开始】、【继续游戏】、【退出关卡】的按钮层级和文案不可互换。
4. 设置开关关闭时，滑块位置必须变化；灰度变化只作为辅助。
5. 自动连锁、完成等待和完成浮层期间，局内暂停与三个道具禁用态必须可辨。
6. 第一夜状态稿不得混入小鸭、鲸鱼或同功能多皮肤。

## 6.4 通过标准

- 致命项必须为 0。
- 主要项不超过 2 项且必须有明确修复排期。
- 次要装饰优化可后置，但不得影响文本、状态、触控和安全区可读性。
