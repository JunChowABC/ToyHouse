# 核心玩法效果图 v7：猫咪和汤风格参考

## 1. 风格分析结论

本版参考《猫咪和汤》的视觉语言，但不复用其角色、设施、图标或品牌元素。

- **线稿**：使用细而轻的暖灰褐铅笔线，保留自然抖动和手绘断续感；不使用《动物餐厅》式粗深棕描边。
- **上色**：透明水彩铺色叠加少量水粉高光，保留纸张颗粒、边缘晕染和局部色差。
- **配色**：以鼠尾草绿、雾蓝、奶油白、浅桃色和浅木色为主，珊瑚红仅用于 Combo 强调。
- **空间**：通过植物前后遮挡、柔和投影和轻微俯视构成森林微缩场景感，不使用塑料高光或三维厚重体积。
- **氛围**：安静、治愈、低对比的夜间绘本感；背景丰富度低于棋盘，确保核心玩法可读。
- **UI**：奶油色手绘纸片框、轻描边、低饱和填色；信息层级清楚，不复制参考游戏 UI。
