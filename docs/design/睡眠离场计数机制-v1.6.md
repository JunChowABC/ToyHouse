# 睡眠离场计数机制 v1.6

2026-09-30。睡眠玩具不再绑定指定唤醒目标。每只睡眠玩具配置 `wake_after_exits`（正整数，小于本关玩具总数），作为自己的初始剩余离场数。

- 任意玩具真实离场时，该关仍睡眠的每只玩具各减1。手动离场的兔子、鲸鱼以及自动离场的鸭子同样计数；同一连锁波中离场多只，逐只递减。
- 一只玩具的同一离场事件只计一次。移动、碰撞、破箱、区域移动和无效点击都不计数。移除道具造成的实际离场同样计数。
- 剩余数归零的那次离场立即触发苏醒、解除操作限制；计数底板和数字当场消失。重开恢复初始剩余数。
- 工作台编辑器提供「睡眠唤醒所需离场数」输入；生成器生成可求解的计数，不再生成 `wake_source` 绑定。依赖图使用通用离场节点表示计数来源。

现有21～100关中120只睡眠玩具已按原无道具解法的实际离场顺序迁移为1～5的计数要求。原80关和新增9关的完整解法仍可通关。新资源 `output/imagegen/mechanics-v2/sleep-count-plate.png` 是经用户已授权的 imagegen CLI 生成的空白紫色布面底板，运行时由游戏绘制实时数字；导出 atlas 的来源、尺寸和哈希在 `assets/mechanics-v1/manifest.json`。

已验证：双鸭同波离场逐次计数、重复离场不重复计数、移除道具计数、三视口画面2→1→苏醒后底板消失、109关源码完整通关、编辑器导入/分析/生成、发布构建无GM。此处更新当前机制定义；早期设计文档中的绑定唤醒关系属于旧版规则。
